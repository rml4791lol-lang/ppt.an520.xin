### 指标口径（已有，直接复用）

- **结构差**：160×90 灰度 → FIND_EDGES → 逐像素平均绝对差（0–255）
- **骨架 IoU**：160×90 边缘掩膜(>40) 各膨胀 1px 的交并比（≈±8px 容差）
- **归一指标** = 结构差 ÷ 原稿 edge 密度（绝对值不可跨本比）
- 实测：一知 55.98 / IoU 0.608 / 归一 1.04 ｜ 普安克 46.80 / 0.569 / 1.09 ｜ 万格 38.46 / 0.398 / 1.17

### 验收口径（工序规范）

`check.py --strict` EXIT=0 ｜ 同册任意两页版式指纹不得相同 ｜ 标题 ink 包围盒 Δw≤8px、Δy≤3px ｜ 硬约束逐 slide 解包复核

## 四、可复用脚本 API

| 脚本 | 用法 |
|---|---|
| `capacity.py` | `capacity(w_px,h_px,sz_pt,text,latin,lins,rins,line_spacing)->(per_line,lines)` |
| `geodiff.py` | `python3 geodiff.py 旧.pptx 新.pptx`，逐形状比 (name,x,y,cx,cy)，"其它"差异必须为 0 |
| `pixdiff.py` | `python3 pixdiff.py dirA dirB [阈值]`，24 页逐像素 |
| `retint.py` | `retint.py in.pptx <行业> -o out.pptx`，10 套行业配色，只改 srgbClr |
| `accept.sh` | 5 步全量验收（渲染+对照+5 组 pixdiff+geodiff+重写报告） |
| `render.sh` | soffice→PDF→pdftoppm 96dpi→联络表；**必须**导 `FONTCONFIG_FILE` |
