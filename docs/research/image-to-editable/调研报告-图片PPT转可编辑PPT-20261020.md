## 0. 一页速读

**六条核心结论**

1. **这是一个"分层"生意，不是一个功能。** 同样叫"图片转 PPT"，实际差距有一个数量级：**L0 塞图**（整页图片改后缀）→ **L1 只认字**（OCR 取字后套模板重排，版式全丢）→ **L2 元素还原**（文字/形状/表格成为原生对象）→ **L3 拍照校正+还原**。市面上约 90% 的"图片转 PPT"产品停在 L0/L1，而用户投诉几乎全部是"我以为买的是 L2，拿到的是 L0/L1"。**验收只需 30 秒：点一行文字，出现光标=文字，出现整页选框=图片。**

2. **国内一线云厂商没有一家提供「图片 → 可编辑 PPTX」的商用 API。** 阿里 DocMind、腾讯 MultimodalDocParse、百度文档解析、火山 LAS 全部只出 **Word / Excel / Markdown / JSON+坐标**。这是明确的产品空位，也是你的机会窗口。

3. **能直接产出可编辑 PPTX 的 API 只有 4 条**（按可落地性排序）：
   - **image2ppt.com** — 图片/PDF → 分层 pptx，**¥0.70–1.00/页**，官方 Python/Node SDK + Webhook + 幂等键，工程完成度最高；
   - **ComPDF Cloud** — `img/pptx` 接口参数最专业（AI 版面分析、公式保留可编辑），**免费 200 文档/月，¥20/月起**；
   - **TextIn PDF转PPT** — **¥0.035–0.08/次**，但只吃 PDF（图片需先转 PDF），QPS 1–10；
   - **度慧 img2doc**（百度/阿里云市场）— **¥0.003–0.017/次**，极便宜，但是 L1 级 OCR 路线。

4. **国内消费级产品里，效果最好的是 WPS AIPPT（当前限时免费），最便宜透明的是 PPTBot（¥0.30/页起），最垂直的是图可编（¥0.98/页）。** 三家都**没有对外 API**——想接只能自己爬/自己仿，不现实。

5. **开源自建没有"开箱即用的可商用引擎"。** 2026 年这一波几乎全是 Codex/Claude Code 的 **Agent Skill**（消耗 LLM token、单页分钟级、不可当 HTTP 服务直调），不是能 `pip install` 后接进后端的库。真正能上线必须自研组装：**PaddleOCR-VL / PP-StructureV3 出 JSON → python-pptx 组装 → LibreOffice 渲染回图 diff → 失败页重修**，MVP 约 **4–8 人周**，单页成本 **¥0.005–0.02**。

6. **效果天花板已经很清楚**：矢量 PDF 80–90 分，规整截图纯文字页 70–80 分，扫描件 60–70 分，**AI 生图整页 PPT 只有 45–60 分**（需求最旺、满意度最低），手机拍屏幕 30–45 分。所有产品撞同一堵墙：**复杂图表必退化成图片、缺字体导致换行错位、箭头/装饰框被并进背景**。

**如果你只想知道怎么选**：

| 你的处境 | 推荐路线 | 上线时间 | 单页成本 | 效果上限 |
|---|---|---|---|---|
| 先验证需求 / 做 MVP | 直接接 **image2ppt.com API** | **3–7 天** | ¥0.70–1.00 | L2，复杂页降级 |
| 要国内合规、要发票、要可控 | **ComPDF** 或 **TextIn 两步直出** | 1–2 周 | ¥0.04–0.18 | L2 / L1.5 |
| 要长期做产品、要毛利 | **自研路线 A**（OCR+组装+渲染回环） | 1.5–2 个月 | ¥0.005–0.03 | L2（可控） |
| 只做"文字可编辑"就够 | **WPS WebOffice OCR API** ¥0.1/页 或 **度慧** ¥0.003/次 | 3–5 天 | ¥0.003–0.1 | L1 |

## 1. 先统一语言：四种"转换"差一个数量级

业内已经收敛出一个清晰分层（SlideForge 的 "image-stuffers vs reconstructors" 二分 + 博客园 8 款实测的 L1/L2/L3，可合并）：

| 层级 | 做法 | 用户到手的东西 | 30 秒验收 | 典型单价 |
|---|---|---|---|---|
| **L0 塞图** | 图片铺满整页，改后缀成 .pptx，最多叠一层隐形 OCR 文本 | 一张照片 | 点文字 → 出现**整页选框** | 免费 |
| **L1 只认字** | OCR 取文字 → 套模板重新生成 | "内容对了、版式没了"的新 PPT | 原图配色/位置**全丢**，但字能改 | ¥0.003–0.1/页 |
| **L2 元素还原** | 视觉模型拆文字/形状/表格/图片，写成原生对象 | 可分层、可改样式的 PPTX | 能**单独选中**某个箭头/卡片 | ¥0.30–2.2/页 |
| **L3 拍照还原** | 透视校正 + 去反光/阴影 → 再走 L2 | 白板/手机拍图的可用稿 | 歪的图变正了 | 基本没有成熟商用 |

**这张表决定三件事**：① 你的产品文案必须按层承诺，否则退款率会失控；② 定价必须按层分档（L1 卖 L2 的价 = 割韭菜，L2 卖 L1 的价 = 亏死）；③ 采购/集成时先问"你给的是哪一层"，比问"效果好不好"有用 10 倍。

> 参考：SlideForge《image-stuffers vs reconstructors》（2026-07-14）；博客园 8 款实测（2026-10-14）。

### 2.2 值得单独说的三家

**① WPS AIPPT —— 目前国内完成度最高，且免费**

官网原文（2026-10-20 抓取）：「Nano Banana Pro 图片转 PPT｜**文本可编辑 字体还原准 图层可分离**｜限时免费」。流程三步：上传 → WPS AI 转换 → 下载或编辑。

- ✅ 真实好评点：文字基本能拆出来改、字体匹配准、**每个小图会单独成图层**、表格能生成为原生表格（单元格可改）
- ❌ 真实差评点（WPS 官方社区一手长评，2025-12 评测活动帖）：
  - 「可编辑元素仍然只有文字，图形元素无法被选中……**对于我来说，该图转换效果是失败的**」（[77441](https://bbs.wps.cn/topic/77441)）
  - 「文字结果错乱，无法选中」；柱形图「直接识别成了一个图片，无法形成动态图表」；「整个 PPT 背景很模糊」；「大结构中的 3 个底框是无法选中的」（[77508](https://bbs.wps.cn/topic/77508)）
  - 「部分图片分辨率下降」「箭头、图标、装饰框被直接归入背景」「文字会有少许错位甚至遗漏，**反而增加了工作负担**」（[77796](https://bbs.wps.cn/topic/77796)）
  - ➗、√ 等符号识别差，背景只识别一部分（[77458](https://bbs.wps.cn/topic/77458)）
- 判断：**中文市场目前最可用的零成本 L2 尝试**，但只在"文字 + 简单卡片"页面成立；一涉及流程图/图表/装饰形状就退回 L1。多位用户给好评的理由是"尚处起步阶段、作为底稿可用"——**没有一条说"可以直接交付"**。

**② PPTBot —— 计费最细、边界最诚实、最便宜**

深圳市比特意图科技有限公司（粤ICP备2026040605号-1），2026-04-13 上线。两大能力：AI 生成 PPT ＋ **「整页图片风格」PDF / 按序 JPG-PNG-WebP → 可编辑 PPTX**。

- 点数价：¥10/100 点、¥30/300、¥60/600、¥120/1200、¥500/5000（**¥0.1/点**）
- 转可编辑：**普通版 3 点/页 = ¥0.30；高精版 15 点/页 = ¥1.50；22 点/页 = ¥2.20**；失败退点
- 附加能力：PPT 换皮（上传已有 PPTX 按模板重出视觉）、品牌视觉、演讲视频
- **官方 FAQ 原文：「转可编辑后能改什么？主要文字可编辑修改，装饰元素可能仍是图片」** ← 这是全行业最诚实的一句披露，值得写进你自己的产品文案

**③ 图可编 tukebian —— 最垂直、定价最透明**

- 定位原文：「高还原、快速地把图片或 PDF 变成可编辑的 PowerPoint」；**1 积分 = 1 页，转换失败不扣积分**
- 价格明码：¥49/50 页（≈¥0.98/页）、¥99/100 页（≈¥0.99/页），新用户验证赠 2 页
- 单任务 ≤100 页，长文档自动分段；支持 JPG/PNG + NotebookLM/扫描版/图片型 PDF（**普通文本 PDF、矢量 PDF 效果不稳定**——很诚实的边界）
- 隐私设计值得抄：源图提交后立即删除、临时文件 24h 清理、PPTX 保留 30 天、任务记录 6 个月
- ⚠️ **当前「库存不足，暂时无法购买」**——按周期配置算力，售完即停售。这本身说明：**L2 的算力成本是真的贵**。

**结论**：这是目前"**接进网站**"性价比最高的选择——有 SDK、有 Webhook、有幂等、有逐页退款账本，工程上几乎所有坑它都替你想过了。缺点是境外主体 + ¥0.7/页 的成本，做 C 端低价产品毛利吃紧，做 B 端/客单价高的场景很舒服。

### 3.4 三条合规红线（做 SaaS 必看）

1. **转售条款**：阿里 API Term of Use 授予的是 **non-transferable、non-sublicensable** → **转售裸 API 违约**，但"封装成自有 SaaS 整体售卖"可以；**腾讯云市场 ISV 协议 5.1/6.6 明确禁止转售**，要接度慧这类云市场商品必须拿**书面 OEM 授权**。
2. **数据出境**：用阿里/腾讯/百度/火山国内 region → 数据不出境，合规最干净；用 image2ppt（新加坡）、Adobe、Nutrient → 数据出境，需评估《个人信息保护法》与客户合同。
3. **"可编辑"的虚假宣传风险**：如果你把 L1 包装成 L2 卖，用户点开发现图形还是图 → 退款 + 差评。**产品页必须写清"文字可编辑 / 元素可分层 / 形状可矢量"三档**，并在转换前做**预检**（告诉用户"这张图不适合还原"）。

### 4.3 三条自研路线

**路线 A（推荐）：结构化解析 → 原生组装** — **4–8 人周，¥0.005–0.02/页**

```
图片/PDF → pypdfium2 分页渲染
  → PaddleOCR-VL / PP-StructureV3：layout + text + table + formula + reading order → JSON
  → 元素分类器（规则 + 小模型）：文本框 / 表格 / 图片块 / 简单几何 / 装饰
  → 文字遮罩 + LaMa 修补底图（保留原像素，不重新生成）
  → python-pptx 组装：真文本框 + 原生表格 + 裁剪图块 + freeform 几何
  → LibreOffice 渲染回图 → 与原图 SSIM/diff → 失败页局部重修
```
优点：全本地、License 全绿、成本可控、可逐页重试、结果可解释。缺点：复杂版式（多栏、图文混排、艺术字）还原一般。

**路线 B：VLM 直出 JSON → 组装** — **2–3 人周，成本高 5–10 倍**
Qwen2.5-VL-7B / InternVL2.5-8B（Apache-2.0 / MIT）强 schema 约束输出元素，再做坐标校验。版式理解最好，但有 bbox 漂移和漏字幻觉，**必须做渲染回环**。建议 **A 为主、B 只兜底 A 的低置信页**。

**路线 C：矢量化重绘（增值功能，不做主线）**
`vtracer`（MIT）→ SVG → DrawingML `custGeom`；或用**内嵌 SVG + 让用户在 PowerPoint 里右键「转换为形状」**这一高杠杆技巧（python-pptx 不支持，需手写 `asvg:svgBlip` 关系）。只对图表/线稿/logo/纯色插画有效；照片、渐变、阴影、艺术字必然劣化。注意 `potrace`/`autotrace` 是 **GPL-2+**，闭源商用高风险。

### 4.4 三个坑

1. **"可编辑"的定义陷阱**：大量项目（OCRPDF-TO-PPT、NBLM2PPTX 等）本质是"**背景图 + OCR 文字层**"。用户点开发现图形还是一张图 → 退费率极高。**必须在文案里分三档：文字可编辑 / 元素可分层移动 / 形状可矢量编辑，并分档定价。**
2. **License 误判**：看徽章、看中文测评 = 必踩坑。逐仓读 `LICENSE` 原文。
3. **成本与时延被低估**：Skill 路线单页 10 分钟+、10 页烧完订阅额度；容量规划要按 `并发 × 页数 × 重试轮次` 算，别按"单页 5 秒"估。

### 5.1 失败模式 Top 8（按出现频率）

### 5.2 分场景效果预期（给产品定价用）

| 场景 | 分数（满分 100） | 瓶颈 |
|---|---|---|
| **矢量 PDF**（PPT 导出的，非扫描） | **80–90** | 字体是否嵌入；图表数据 |
| 整页截图（规整、纯文字 + 卡片） | **70–80** | 图形层、字体；需留 20–30% 微调 |
| 扫描件（印刷体、平整） | 60–70 | 去噪、表格线 |
| **AI 生图整页 PPT**（Nano Banana / GPT-Image） | **45–60** | 艺术字与背景强耦合，重绘后模糊——**需求最旺、满意度最低** |
| 白板照片（手写 + 箭头） | 40–55 | 透视、反光、手写体 |
| 手机拍屏幕 | **30–45** | 摩尔纹、反光、透视 |
| 密集信息图 / 科研图 | 30–45 | 元素密度、连线；硬转会"很自信地错" |

**一句话**：能做到 80 分的只有"矢量 PDF"和"规整截图纯文字页"；只能到 40 分的是"手机拍屏幕""密集信息图""白板照"。最尴尬的是 AI 生图——**它的高级感恰恰来自渐变、光效、插画这些最不可能被结构化的像素**。

- V2EX 2026-07《有没有牛逼的图片转 PPT 的工具》905 浏览 **0 回复**——问的人多、答的人少，说明没有公认解

## 6. 成本与商业模型

### 6.1 单页成本对比

| 方案 | 单页成本 | 备注 |
|---|---|---|
| 度慧 img2doc | **¥0.003** | 按次，一次可多图；L1 |
| 自研路线 A（本地 GPU） | **¥0.005–0.02** | 折旧+电费，不含工程 |
| VLM API 直出（豆包/千问） | **¥0.05–0.30** | 输入 $0.12/M、输出 $1.15/M 量级 |
| 腾讯 MultimodalDocParse | **¥0.04–0.08** | 原料层 |
| TextIn PDF→PPT | **¥0.035–0.08/文件** | 按文件不按页 |
| WPS WebOffice OCR | **¥0.06–0.10** | L1 |
| **image2ppt.com** | **¥0.70–1.00** | L2，含全部工程 |
| PPTBot 普通 / 高精 | **¥0.30 / ¥1.50–2.20** | L2 |
| 图可编 | **¥0.98** | L2 |

**关键结论：商业 L2 API 与自研成本之间有 30–140 倍价差。** 这意味着：只要你有量（>2 万页/月）且有工程能力，自研回本很快；反之直接接 API 更划算。

### 6.2 三种落地路线

| | 路线 1：纯集成 | 路线 2：混合 | 路线 3：全自研 |
|---|---|---|---|
| 做法 | 直接接 image2ppt / ComPDF | 商业 API 主力 + 自研兜底/降本 | 路线 A + 渲染回环 |
| 上线时间 | **3–7 天** | 3–4 周 | 1.5–2 个月（MVP）、3–6 个月（稳定） |
| 单页成本 | ¥0.70–1.00 | ¥0.30–0.70 | ¥0.005–0.03（+GPU 约 ¥2–4k/月） |
| 效果 | 平台给什么就是什么 | 可控 | 可控、可迭代 |
| 风险 | 供应商依赖、境外主体、涨价 | 双轨复杂度 | 工程投入大、效果爬坡慢 |
| 适合 | 验证需求、B 端项目制 | 已确认有量 | 长期产品 |

### 6.3 定价建议

- **按层分档**：文字可编辑 ¥0.5–1/页；元素可分层 ¥2–3/页；形状可矢量 ¥5+/页（或按次项目报价）
- **订阅**：¥39–69/月含 60–100 页（对标 PPTBot ¥0.3/页、图可编 ¥0.98/页，你的毛利在 60–85%）
- **B 端**：¥0.3–0.8/页 + 年框；含私有化另计
- **免费档**：给 2–3 页（这是全行业标配，WPS 免费、图可编送 2 页、PPTBot 送点）
- **必须做的**：转换前**预检**（判断这张图属于哪种场景、预计可编辑比例），难例直接劝退或降级到"保真贴图"，比事后退款便宜 10 倍

## 7. 我的建议（如果我是你）

**第一步（本周）：花 1 天做 10 图 × 5 工具的盲测。**
用同一批图（矢量 PDF / 规整截图 / 扫描件 / AI 生图 / 手机拍屏 各 2 张）跑：image2ppt.com、ComPDF、WPS AIPPT、PPTBot、图可编。评分三项：**文字 CER、文本区域位置 IoU、可编辑元素数（Ctrl+A 能选中几个独立对象）**。**这比读任何测评都可靠**——因为这个品类 90% 的公开评测是软文。

**第二步（据盲测结果）**：
- 若 image2ppt 的效果可接受 → **直接接它的 API 上线**，3–7 天出 MVP，先把用户和场景跑起来；
- 若必须国内合规/要发票 → **ComPDF（国内团队）+ 度慧（免费档）** 双轨；
- 若目标客群是"教师/课件/旧资料截图"（L2 需求最刚、且 WPS 免费在打）→ 你必须自研才有差异，**路线 A 起步**，用 `px-image2pptx`（MIT）做起点。

**第三步（产品设计上的三个必做）**：
1. **预检 + 分层承诺**：别承诺"还原"，承诺"分层交付 + 可编辑比例预检"；
2. **三档定价**：文字/元素/形状分开卖，这是行业里唯一没有争议的定价方式；
3. **字体策略显式化**：缺字体时**告知用户**而不是偷偷栅格化——这是 WPS 用户差评最集中的技术点之一。
