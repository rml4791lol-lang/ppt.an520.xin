# 国内「图片型 PPT / 截图 / 扫描版 PDF → 可编辑 PPTX」产品调研

- **抓取日期**：2026-10-20（北京时间）。价格与功能均以该日官网/官方页面为准；部分页面为 JS 渲染，已标注「未能静态抓取」。
- **调研范围**：国内可访问的网站、桌面/移动工具、开放平台 API，共 24 个产品 + 3 个开源方案。
- **方法**：web_search / 百度·搜狗检索 → 官网 web_fetch 原文核实 → 论坛/评测交叉验证。凡未读到官网原文的，标注为「未核实」，不做推断。

---

## 0. 一句话结论

> 国内**真正**把「整页图片还原成可编辑元素」的产品，到 2026-10 为止仍然只有个位数（WPS AIPPT、PPTBot、图可编、i2ppt、Kimi PPT、智在PPT〔存疑〕），且**全部是 2025-12 之后才上线的**。市面上 90% 打着「图片转 PPT」旗号的产品，实际是「OCR 取字 → 重新生成一份新 PPT」，版式、配色、图形全部丢失。**没有任何一家提供「图片 → 版式还原 PPTX」的公开 API**，这是明确的产品空位。

---

## 1. 分类标准（本笔记的核心区分）

| 类别 | 定义 | 判定标准 | 对用户是否有用 |
|---|---|---|---|
| **A1 真还原** | 解析页面结构，输出**分层** pptx：文本框是真文本、简单图形是原生形状、复杂图标是 PNG 素材 | 导出后能在 PowerPoint 里**单独选中**标题/正文/色块/线条 | ✅ 解决 |
| **A2 半还原** | 文字变真文本，但**图形/底框/图表整体是图片**，版式靠贴图「看起来像」 | 文字可改，形状选不中 | 🟡 部分解决 |
| **B 生成类** | 只取文字内容，重新套模板生成**全新** PPT，与原图版式无关 | 输出与原图完全不同 | ❌ 不算解决（仅对照） |
| **C 伪转换** | 把图片按页贴进 pptx，一页一张图；或 PDF→PPT 只对文字型 PDF 有效 | 整页是一张图 | ❌ 完全不算 |
| **D 无关** | 图像修复/OCR 工具，不产出 pptx | — | ❌ |

## 3. 逐产品详录

### 3.1 WPS / 金山办公 —— 目前国内完成度最高的消费级方案

**产品名**：WPS AIPPT「图片转 PPT」（Nano Banana Pro 驱动）
**入口**：https://aippt.wps.cn/aippt/convert-ppt/
**官网原文（2026-10-20 抓取）**：

> WPS AIPPT 图片转 PPT｜1 上传图片 → 2 WPS AI 转换 → 3 下载或编辑
> **Nano Banana Pro 图片转 PPT｜文本可编辑 字体还原准 图层可分离｜限时免费**
> 支持 30 张以内不大于 20MB 的 PNG、JPG、JPEG、WEBP 图片，支持单个不大于 100MB 的 PDF 文档

- **输入**：≤30 张图片（单张 ≤20MB）；单个 PDF ≤100MB
- **输出**：可在线编辑，或下载为 PPT
- **价格**：当前**限时免费**。WPS AI 会员自 2024-04-01 起独立收费，**连续包月 25 元/月**（IT之家报道），大会员 = AI 会员 + 超级会员 Pro。图片转 PPT 正式收费后大概率并入 AI 会员权益（**未获官方确认**）。
- **效果（真实用户长评，bbs.wps.cn/topic/77508，2025-12）**：
  - ✅ 文字「基本可以识别」，字体还原准确，文字/图片大小可调，**每个小图会单独成图层**
  - ❌ 「文字结果错乱，无法选中」；柱形图**直接被识别成一张图片**，不能变成可编辑图表；底框、贯穿动线、节点**无法选中**；转换后清晰度不够，背景发糊
  - 用户原话：「大结构中的 3 个底框是无法选中的……相对来说是一种固定、死板的结构」
  - → 判定 **A2**：文字层真还原，图形层部分还原，复杂图表降级为图片
- **API 能力（关键）**：WPS **WebOffice 开放平台**（https://solution.wps.cn/）明确列出：
  - OCR 文字识别：**「图片转 Word、Excel、PPT、JSON」**，阶梯价 **0.1 元/页**（1–1 万页/月）、0.08 元/页（1–10 万）、0.06 元/页（10–100 万）、>100 万另议
  - 在线格式转换：Word/Excel/PPT/PDF 互转与转图，**0.1 元/次**（1–100MB）
  - ⚠️ 注意：这是 **OCR→结构化 PPT**，不是「版式还原」；WPS AIPPT 的 Nano Banana 还原能力**未对外开放 API**
- **其他入口**：WPS 灵犀（客户端内）走的是「提取文字 → 立即生成」链路，属 B 类，**不是**还原

**百度文库 AI PPT**
- 有「图片导入」入口，但流程是：**OCR 识别文字 → 自动生成新大纲 → 选模板 → 生成新 PPT**
- 第三方横评原话：「它做的事情是『识别文字-生成新大纲-选模板生成新PPT』，而不是直接还原原图的版式……不会继承图片中的布局、配色、图形元素」；生成的 PPT 文字/形状可编辑，但配图多以图片形式存在
- 判定：**B**。适合「从图里捞文字重做」，不适合「复用旧版式」

**百度网盘 AI / 文心一言**：未见「图片→可编辑 PPT」专属功能，文心偏向文本生成。

**夸克**：路径为「扫描王拍照 → 识别文字 → 转为 PPT（自动切分标题层级）→ 导出 PPTX」。同样是**大纲式重排**，非还原。判定：**B**。

### 3.9 腾讯系

- **腾讯文档 AI**：支持「图片/Markdown → 思维导图」，再由思维导图生成 PPT；**没有**图片→可编辑 PPT。
- 值得一提的技术线索：2020 年 QQ 研发中心公开过自研「PPT 图片重建技术」，「目前腾讯文档在进行接入工作」（community.aijishu.com）——但**至今未作为公开功能上线**。
- **腾讯 ARC**：图像修复/人像处理实验室，与 PPT 无关。判定：**D**。

### 3.11 转换器类（迅捷 / 嗨格式 / 福昕 / 万兴 / 极速 / Smallpdf / iLovePDF / Convertio）

**这一类基本都不解决问题，必须说清楚为什么：**

- 它们的「PDF 转 PPT」做的是 **PDF 内部对象 → PPT 对象**的映射。对**文字型/矢量型 PDF**（原生导出的 PDF）效果尚可；对**扫描版/图片型 PDF**，因为 PDF 里只有一张位图，转换结果就是**每页一张大图**贴进幻灯片——看似成功，实则完全不可编辑。
- 迅捷 PDF 转换器价格（官网 FAQ）：**48 元/半年、88 元/一年、118 元/终身**；App 端月 30/年 58/终身 78。
- 福昕、万兴、极速、iLovePDF、Smallpdf、Convertio 模式相同，多为「免费额度 + 订阅」。
- **识别技巧**：转换后打开 pptx，若每页只有一个 picture 对象、Ctrl+A 只能选中一张图 —— 就是 C 类伪转换。

判定：**C**。可作为「PDF 里有文字层」场景的低价兜底，但不能作为「图片型 PPT」方案。

### 3.12 设计工具类（稿定 / 创客贴 / 比格 / 图怪兽 / Canva）

- **稿定设计**：模板化在线设计。下载时可选 **「PPT 文件」格式**，并可勾选「**PPT 内文字可编辑**」或「文字不可编辑」，其中「文字可编辑」**仅会员可用**（官方帮助文档）。本质是「自己排版 → 导出」，不是「上传图片 → 还原」。判定 **C→B**。
- **创客贴 / 比格 / 图怪兽**：同上，导出以图片/PDF 为主，PPTX 多为整页图。判定 **C**。
- **Canva 可画（国内版）**：可导出 PPTX，但官方明确「支持 PowerPoint 格式下载**仅出于兼容性目的**」，并提示「请不要在 Canva 可画外编辑你下载的 PPTX 文件」——即导出物是**版式快照**，不是可编辑对象树。判定 **C**。

## 5. 竞品能力边界（所有产品都撞在同一堵墙上）

汇总各家的官方 FAQ + 用户实测，失败模式高度一致：

1. **复杂图表**（柱状图/饼图/流程图）→ 退化为一张图片，不能改数据（WPS 用户实测、图可编官方说明、智在PPT FAQ 均承认）
2. **字体**：图片不含字体文件，只能「仿字形」。缺字体 → 换行、字距、位置全偏（图可编专门写了 FAQ）
3. **多层装饰/渐变/发光/图标** → 要么糊成一块，要么切碎后惨不忍睹（slide-alchemy 明确定义了「什么时候必须保留 PNG」）
4. **大面积底框/动线/连接线** → 经常整块不可选（WPS 实测最典型）
5. **手写/白板/翻拍** → 识别率断崖下跌，各家都建议「用截图，别拍屏幕」
6. **清晰度**：转换后背景常发糊（WPS 实测）

**行业共识做法**（可直接借鉴）：底图用图像编辑模型重绘 → 文字走 OCR + 字体匹配 → 简单形状转 OOXML 原生几何 → 复杂图标生成透明 PNG → 组装 pptx。

## 6. 用户评价汇总（区分「文字可编辑」与「版式/图形可编辑」）

## 8. 对「做网站产品」的启示

1. **市场窗口是开的**：真正的竞品只有 4–5 家，且全部 2025-12 之后上线，没有一家形成品牌壁垒；WPS 靠免费在打，垂直小厂靠 ¥1/页在收。
2. **定价可对标**：按页 ¥0.5–1.0 是用户已被教育的区间（图可编 ¥0.98、PPTBot 高精 ¥2.2）；免费给 2–3 页试用是标准动作（图可编送 2 页、PPTBot 赠点、WPS 限时免费）。
3. **差异化只能做在「还原度」上**：所有人文字都能做，所有人图表都做不好。谁能把**图表/表格还原成可改数据**、把**字体度量对齐**做好，谁就有壁垒。
4. **API 是空白赛道**：现有玩家全是 C 端订阅，没有 B 端 API。若做网站产品，**对外提供「图片→pptx」API + 按页计费**本身就是差异化（可参考 WPS OCR ¥0.1/页 作为成本锚点）。
5. **必须诚实标注能力边界**（像图可编、PPTBot 那样写 FAQ），否则退货/差评会吃掉利润——这是这个品类最容易翻车的地方。
6. **合规**：涉及 OCR 与生成式模型，需注意深度合成算法备案（iSlide 已备案第 4 批）、以及用户上传 PPT 的商业敏感信息（图可编的「源图提交后即删」是可抄的信任设计）。
